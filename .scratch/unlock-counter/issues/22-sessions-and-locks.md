# 22: Sessions and locks

**What to build:** Log locks next to unlocks and show each unlock-to-lock span as a session on the day screen. A screen-off counts as a lock. Each line in `unlocks.log` gets a type, `unlock` or `lock`; a line with no type reads as an unlock, so the existing log needs no migration. A session shorter than the glance limit is a glance, drawn in the burst orange. The History tab and the wallpaper stay unlock-only.

Mockup: https://claude.ai/artifact/A9Dw9dqDzBRPZWDWDYnnv1 ("Picked design" section)

Day screen, for a day with lock times:

- Strip: unlock ticks, glance ticks in orange, unlabeled hour ticks under the strip next to the hour labels
- "Session length" card, unfolded by default: histogram rows < glance limit (orange), up to 10, 10–30 and 30+ min
- "Statistics" card, folded by default, one stat per row: First unlock, Last lock, Longest off, Median off, Screen time, Bursts
- Fold state is not remembered
- Timeline: one row per session with start – end, length and a length bar; glance length and bar in orange, burst start time in orange; a break reads "N min locked"

Edge cases:

- Open session today: the row reads "start – now", its bar is dashed, and screen time counts it up to now
- A day with no lock times: the current unlock-only view, Statistics card with unlock gaps (First unlock, Last unlock, Longest gap, Median gap, Bursts), no Session length card, and a note "Lock times start on …"
- An unlock with no lock before the next unlock: the row shows only the start; screen time and the histogram skip it
