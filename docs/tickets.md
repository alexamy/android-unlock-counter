## T5 False lock after a wake within the lock grace

The phone has `lock_screen_lock_after_timeout` = 5000 ms. When the screen times out, the app logs a lock on `ACTION_SCREEN_OFF`. When the user wakes the phone within 5 s, Android returns to the last app without the lock screen and sends no `ACTION_USER_PRESENT`. The session continues, but the log says the phone is locked:

- The session ends early, so screen time is too low.
- The next real lock is dropped, because `CounterStore.addLock` logs one lock per unlock.

Reproduced on 12 Nov 2026 at 11:35: lock logged at 11:35:28, no unlock after the wake.

Fix direction: on `ACTION_SCREEN_ON`, check `KeyguardManager.isKeyguardLocked`. When it is false, the session continues. How to write this to the log is open: remove the lock, or log a resume event.
